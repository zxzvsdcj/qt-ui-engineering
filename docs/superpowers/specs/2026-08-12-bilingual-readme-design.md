# 双语 README 设计规格

**日期：** 2026-08-12  
**状态：** 用户已批准方案 A  
**项目：** `qt-ui-engineering`

## 1. 目标

让公开 GitHub 仓库首页默认展示完整中文说明，同时保留内容等价的英文文档，方便中文读者快速理解项目，也不降低英文读者的可访问性。

## 2. 文件职责

- `README.md`：GitHub 默认渲染的简体中文项目首页。
- `README.en.md`：从当前 `README.md` 保留的完整英文版本。
- 两份文档首行均提供明确的语言切换入口：`简体中文 | English`。

不新增额外国际化工具、生成脚本或依赖。两份 README 都是可直接维护的 Markdown 文档。

## 3. 内容结构

中文版与英文版保持相同章节顺序和技术含义：

1. 项目定位与技术栈保护原则；
2. 三层核心模型；
3. 支持矩阵；
4. 安装方式；
5. 使用方式与输出契约；
6. 静态技术栈检测；
7. 设计产物；
8. 验证与六类评测场景；
9. 项目结构；
10. 来源与综合方式；
11. 已知限制。

代码、命令、文件路径、Skill 名称、Qt API 名称和外部链接保持原样，不做翻译。说明性文本采用自然、准确的简体中文，不逐字硬译。

## 4. 导航设计

两份 README 顶部使用同一组语言入口：

```text
[简体中文](README.md) | [English](README.en.md)
```

当前语言使用粗体标识，帮助读者确认所在版本：

- 中文版：`**简体中文** | [English](README.en.md)`
- 英文版：`[简体中文](README.md) | **English**`

## 5. 一致性约束

- 中文版不得省略英文版的功能说明、限制或验证信息。
- 英文版不得继续把仓库描述为私有仓库。
- 两份文档中的安装命令和仓库 URL 必须一致。
- 本地会话记录仍保持仅本地保存，不加入任一远程 README 链接。
- 后续若改变功能、安装方式或限制，应同步更新两份 README。

## 6. 实施范围

1. 将当前英文 `README.md` 复制为 `README.en.md`，并添加语言导航。
2. 将 `README.md` 重写为完整中文版本，并添加语言导航。
3. 不修改 `SKILL.md`、检测器、适配器、模板或测试逻辑。

## 7. 验证标准

- `README.md` 和 `README.en.md` 均存在，且 GitHub Markdown 相对链接有效。
- 中文版包含全部 11 个对应章节及六类评测场景。
- 两份文档的命令、仓库 URL 和关键 Qt 技术名称一致。
- `python -B scripts/validate_skill.py .` 通过。
- `python -B -m unittest discover -s tests -v` 全部通过。
- `git diff --check` 无空白错误，工作区最终干净。

## 8. 风险与处理

- **双语内容漂移：** 用相同章节顺序和顶部互链降低维护遗漏，并在 README 中明确同步更新要求。
- **翻译改变技术含义：** 保留所有技术标识和命令原文，以语义等价而非逐字翻译为准。
- **首页仍显示英文：** 中文版固定使用 GitHub 默认识别的 `README.md` 文件名。
